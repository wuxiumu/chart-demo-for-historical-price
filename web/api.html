本页描述本站对外提供的全部行情查询接口：免鉴权、JSON（UTF-8）、支持跨域（CORS *）。 数据为第三方公开行情的整理展示，仅供研究与可视化演示，不构成任何投资建议。
🤖 AI 快速接入：直接抓取纯文本文档 api.md（本页的 Markdown 版，含字段字典与调用示例）， 或在提示词中写明「请阅读 <站点地址>/api.md 并按文档调用接口」。

基本信息

  • Base URL：http://localhost:8787（默认本地端口，实际部署替换为站点地址）
  • 统一响应：{ "code": 200, "msg": "ok", "data": … }，code === 200 为成功
  • 市场代码：market=17 沪市 · market=33 深市；股票代码为 6 位数字
  • 限频建议：单接口 ≤ 1 次/秒；盘中约 5~15 秒更新一轮，非交易时段无新数据
  • 交易时段（Asia/Shanghai）：周一至周五 09:25–11:31、12:55–15:05

1. 服务健康检查

GET /api/health 
{ "code": 200, "msg": "ok", "hasToken": true, "ts": 1792983149108 }

hasToken=false 时行情数据通道未配置，/api/stock-list 与 /api/kline 可能不可用。

2. 自选股实时快照

GET /api/stock-list

看板全部自选股实时报价。非交易时段可能返回空数组。主要字段：stockCode / stockName / market / currentPrice / changePrice / changePercent / openPrice / highPrice / lowPrice / prevClose / fluctuationPercent(振幅) / volume / turnover(成交额) / turnoverRate。

3. K线数据（日K / 分时）

GET /api/kline?market=17&code=600519&type=DAILY&adj=1
参数说明
market17 沪 / 33 深，默认 17
code6 位代码，必填
typeDAILY 日K（默认）/ INTRADAY 当日 1 分钟分时
adj1 前复权（默认）/ 0 不复权，仅 DAILY 生效

响应 data[0].klineData 为数组套数组，每根 K 线长度 10：

[20260105, 1325.4, 1341.98, 1324.79, 1337.02, 17400000, 23250000000, 2.02, 0.15, null]
  日期      开       高       低      收      成交量     成交额(元)   涨跌额 涨跌%  预留
  • DAILY 日期为 YYYYMMDD 数字（2025 年初起约 435 根）；INTRADAY 下标 0 为 Unix 秒时间戳，仅最后一个动态点为毫秒（>1e12 时 ÷1000）
  • 成交量单位注意：DAILY 历史 bar 为「股」，盘中最后一根动态 bar 可能为「手」，可用 量×收盘价 ≈ 额 判定（成立为股，差 100 倍为手）
  • 昨收取「上一根不同日期」的收盘价——非交易日最后一根可能被复制，直接取倒数第二根会得到假 0 涨跌

4. 五档盘口

GET /api/quote5?market=17&code=600519

响应 data.quote_data[0] 含 data_fields（字段名数组）与 value[0]（数值），必须按字段名对位取值（顺序不保证）：

字段名含义
24/26/28/150/154 + 25/27/29/151/155买1–买5 价格 / 挂单量（股，÷100=手）
30/32/34/152/156 + 31/33/35/153/157卖1–卖5 价格 / 挂单量（股，÷100=手）

5. 当日逐笔成交明细

GET /api/trace?market=17&code=600519

响应 data.quote_data[0].value 为最近 100 笔，每笔 [毫秒时间戳, 成交价, 方向, 当日累计量(股), 单笔量(股)]；方向 1 买盘 / 2 卖盘 / 3 中性；单笔量 ≥100 时 ÷100 显示为「手」。

6. 股票搜索（全市场联想）

GET /api/search?q=茅台

按代码 / 名称 / 拼音联想，最多 10 条：[{ code, name, market, label }]，可用其中的 code + market 直接调用上面的行情接口。

典型调用流程

  • /api/health 确认服务可用 → /api/search 定位股票 → /api/kline?type=DAILY 取日K（最新有效 bar 收盘即现价）
  • 盘中补充 type=INTRADAY、/api/quote5、/api/trace，5 秒级轮询即可
  • 失败请读取 code 与 msg，至少等待一个刷新周期后再重试，勿盲目高频请求
